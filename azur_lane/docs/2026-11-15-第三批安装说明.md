## Windows 操作

在仓库根目录 `D:\project_python\live2d-game-artifact-gallery` 中执行：

```powershell
git pull origin main
python azur_lane/scripts/install_batch3.py --plan
python azur_lane/scripts/install_batch3.py
python -m http.server 8000
```

在浏览器打开 <http://127.0.0.1:8000/azur_lane/viewer/batch3.html>，或从主展厅打开 `azur_lane/viewer/index.html` 查看完整模型列表。

只安装优先核查的皮肤：

```powershell
python azur_lane/scripts/install_batch3.py --only gaoxiong_7 aogusite_4 xingdengbao_3 mojiaduoer_4 meikelunbao_2
```

若清单过旧，可使用 `--refresh` 拉取最新元数据和 hash 清单；如果原画不完整，用 `--force-paintings` 重建目标 PNG。已缓存包按 MD5 验证，下载失败可直接重跑。

独立报告保存为：`azur_lane/data/batch3-install-report.json`（不提交 Git）。第二批依然写入 `batch2-install-report.json`；两批不会相互覆盖报告。

## 本次补充的质量控制

- **UnityPy 版本回退**：复用当前 `rebuild_painting.py` 中的 `config.UNITY_FALLBACK_VERSION`，不再以裸 `UnityPy.load` 忽略回退配置。
- **立绘**：识别实际 PNG 文件头，重建使用临时文件并在验证成功后替换旧图。
- **模型**：必须同时具备有效 `MOC3`、`model3.json` 和所有列出的贴图；不完整模型不应进入展示清单。
- **增量**：已有完整模型无需重复提取，缺文件则重新尝试；可用文件按资源名字精确匹配，避免相似资源名误装。
- **结果与效果分离**：报告标记 `live2d_files_ready` 仅说明文件层面可用，`animated_effect_verified=false`；**不意味着**复杂特效、交互或双形态已经百分百复现。
- **封面**：卡片优先读取已重建 PNG，不存在时显示占位提示。若仍破图，先查看报告中 `paintings_built/expected`，再检查本地文件与 manifest。
