## Windows 安装

在仓库根目录，更新 `main` 后：

```powershell
git switch main
git pull --ff-only origin main

# 首先检查本地 EN 服版本 hash 清单是否包含这些路径，不下载
python azur_lane/scripts/install_batch8.py --plan

# 安装这一批 20 款
python azur_lane/scripts/install_batch8.py

# 重新生成跨游戏索引及文件状态报告，启动本地服务
python scripts/gallery.py serve --port 8000
```

浏览器：
- 碧蓝航线统一操作台：`http://127.0.0.1:8000/azur_lane/viewer/index.html`
- 跨游戏资源目录：`http://127.0.0.1:8000/gallery/`

只试两套：

```powershell
python azur_lane/scripts/install_batch8.py --only suweiaitongmeng_3 rangbaer_4
```

本地元数据或 CSV 版本过旧时，可以先刷新再安装：

```powershell
python azur_lane/scripts/install_batch8.py --refresh
```

`--refresh` 会访问外部服务，首次下载依赖本地网络、可用代理及 CDN。

## 安装报告与筛选准则

报告：`azur_lane/data/batch8-install-report.json`（本地忽略，不提交素材）。
必须确保逐项的 `paintings_expected > 0`、`models_expected > 0`，
并且 `paintings_built == paintings_expected`、`models_built == models_expected`。
否则安装器以不完整状态退出。

所有资源默认 `review_status=pending_visual_and_motion_review`、
`footwear_verified=false`、
`all_motions_verified=false`。

只有完整人物和各触摸/切换/待机动作都符合“穿鞋、脚部被遮挡、不出现赤脚”
才可以升级为通过。无需删除不合格的下载素材，只需调整收藏筛选标记或配置。

**严禁**把外部换装名、形象风格、皮肤资源完整性等同于鞋履真实通过。
