## 安装
在 Windows 项目根目录：

```powershell
git pull origin main
python azur_lane/scripts/install_batch6.py --plan
python azur_lane/scripts/install_batch6.py
python -m http.server 8000
```

打开 `http://127.0.0.1:8000/azur_lane/viewer/batch6.html`，预览人物立绘、下载/动作状态，全部动作检查后手动标记“全动作包脚”或“存在露脚”。筛选状态记录在浏览器 localStorage；各批次资源不会重命名或混淆。

只下载赛车长靴初筛两款：

```powershell
python azur_lane/scripts/install_batch6.py --only xinnong_3 dafeng_2
```

## 验证边界
- 当前确定：20 个基础 L2D bundle 路径和 20 个对应 `painting/..._tex` 在提交时的 hash 清单中存在；排除了现有仓库 manifest 的模型重复。
- **立绘初筛**：信浓 `xinnong_3`（Moonlit Chrome）、大凤 `dafeng_2`（Enraptured Companion）；其余18款鞋履仍待核实，不能承诺不露脚。
- 这一步没有实际下载用户本地模型，也没有实测全部互动。批次报告将写入 `azur_lane/data/batch6-install-report.json`，并强制 `footwear_verified=false`、`all_motions_verified=false`。
- 安装器复用项目已有 MD5、UnityPy、model3.json、PNG 重建和 manifest 生成流程；对多模型变体严格计数。不要提交第三方版权模型/立绘/AssetBundle。
