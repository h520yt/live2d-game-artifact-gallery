## Windows 安装

在 `D:\project_python\live2d-game-artifact-gallery` 根目录打开 PowerShell：

```powershell
git pull origin main
python azur_lane/scripts/install_batch4.py --plan
python azur_lane/scripts/install_batch4.py
python -m http.server 8000
```

访问 <http://127.0.0.1:8000/azur_lane/viewer/batch4.html>，或打开 <http://127.0.0.1:8000/azur_lane/viewer/> 查看全量模型。

可以用 `--only` 精确安装某几款，不必全部下载：

```powershell
python azur_lane/scripts/install_batch4.py --only feiteliedadi_4 jinluhao_3 sitelasibao_2
```

如清单过旧，可加 `--refresh` 更新资源索引；如果已有 PNG 不完整，添加 `--force-paintings` 强制重建。

下载中断后可直接重跑，同尺寸缓存会按 MD5 校验；仅当需要重建文件时才再次提取。安装报告位于 `azur_lane/data/batch4-install-report.json`，与第二、三批相互隔离。

## 完整性与回归验证

安装入口复用项目已有 UnityPy 版本回退、临时 PNG 重建、MD5 校验以及 moc3/贴图文件验收。第四批额外对报告做严格校验：**立绘全部、模型全部（包括 `_hx` 变体）齐全**，否则 `status=incomplete` 且程序返回非零状态；`animated_effect_verified` 仍为 `false`，避免将文件提取成功等同于完整动态还原。

```powershell
python -m unittest discover -s azur_lane/tests -p "test_install_batch*.py" -v
```
