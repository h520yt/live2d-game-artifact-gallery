## 安装指令（Windows）

将本补丁 ZIP **解压到已有的** `D:\project_python\live2d-game-artifact-gallery` 根目录，按路径合并文件；旧项目文件不需要覆盖。

在仓库根执行：

```powershell
python azur_lane/scripts/install_batch2.py --plan
python azur_lane/scripts/install_batch2.py
```

如果资源清单旧或对应皮肤缺少资源，则使用：

```powershell
python azur_lane/scripts/install_batch2.py --refresh
```

如果下载中断，直接重跑即可；缓存会按 MD5 校验后跳过。

只装其中某几款：

```powershell
python azur_lane/scripts/install_batch2.py --only guanghui_9 baifeng_3
```

仅在原画重建不完整时使用 `--force-paintings`。执行结束后，安装记录保存在 `azur_lane/data/batch2-install-report.json`。

启动网页：

```powershell
python -m http.server 8000
```

访问 **第二批专属页面**：<http://127.0.0.1:8000/azur_lane/viewer/batch2.html>。

原有完整展厅：<http://127.0.0.1:8000/azur_lane/viewer/>。第二批页面支持中文皮肤名搜索、类型筛选和不同立绘变体切换。

## 动效限制

- 4 款 Live2D+：已定位 `L2D.csv` 模型资源，脚本下载并使用现有 Cubism 提取链路，浏览器中的动作与交互效果需要实际验证。
- 1 款特殊动态、5 款普通动态：`L2D.csv` 当前未收录对应模型，**脚本只能安装静态立绘**。完整动态可能依赖其他资源体系或官方动画管线，此补丁没有臆造动画，也没有把静态 PNG 当作动态安装成功。
- `batch2-install-report.json` 的 `animated_effect_verified` 始终为 `false`，只有实际打开网页测试后才能确认。
- 游戏资源属于游戏开发商，仅供个人研究、查看；请勿公开打包分发。
