## 本地安装

在项目根目录运行：

```powershell
git pull origin main
python azur_lane/scripts/install_batch5.py --plan
python azur_lane/scripts/install_batch5.py
python -m http.server 8000
```

浏览 `http://127.0.0.1:8000/azur_lane/viewer/batch5.html`；完整模型工作台仍是 `/azur_lane/viewer/`。

按款安装示例：`python azur_lane/scripts/install_batch5.py --only ougen_5 qiye_7`。若 hash/元数据较旧，可添加 `--refresh`；中断后重跑可以复用校验通过的缓存。

## 资源与验收边界

- 官方/社区资源 hash 索引已包含这 20 个基础 Live2D 名称（部分有 `_hx` 变体），但提交代码时**未运行你本地的 CDN 下载或浏览器动作测试**。
- 安装器从本地 `ship_skin_template.json` 读取 skin ID，不能通过相近拼音猜测；走已有 MD5、UnityPy、PNG 重建与模型验收逻辑。
- 安装报告为 `azur_lane/data/batch5-install-report.json`（Git 忽略）；立绘包与模型变体必须全部齐全，才属于文件级就绪。
- 文件级就绪不等于完整复原游戏特殊动作、双形态、动态效果；所有结果 `animated_effect_verified=false`、`footwear_visually_verified=false`，仍需本地播放和鞋履复核。
- 浏览器卡片不拿错位缩略图充数：未安装展示缺图状态；只读取本地 `manifest.json` 和本批报告。
- 严禁提交模型、贴图或游戏原始 bundle。仅供个人学习、研究和预览。
