# 精选皮肤筛选规范 · 成熟画风优先

## 筛选顺序

1. **人物整体成熟画风**：优先成熟御姐、成年感明显的人物。出现明显儿童感、幼态比例或过度稚嫩画风时，排除出成熟精选候选。**不能仅凭游戏角色设定或姓名推断实际年龄**，拿不准先暂停等待完整立绘人工核对。
2. **完整姿态与构图**：观察角色是否具有完整且符合成熟审美的造型，包括服装、整体气质和视觉表现；不得以单独露出的腿部或鞋子决定收录。
3. **鞋履与动作条件**：鞋履优先长靴、短靴、马丁靴、运动鞋、高跟鞋、包脚鞋；足部被遮挡也可以继续审核。逐一确认 idle、触摸、换装、特殊镜头，不应把原始模型入口齐全当作视觉审核通过。
4. **资源技术可用性**：最终再确认 Live2D 或动态资源存在、可下载、贴图与动画可还原，并避免与既有皮肤重复。

## 批次配置状态

第七批及后续在 `curated_collections.json` 每个条目必须设置 `maturity_screen`：

- `candidate`：成熟风格初筛候选；**不代表已完成真人视觉审核或动作审核**，可进入资源安装流程供进一步检查。
- `hold`：人物整体成熟度尚不确定，**暂停参与精选安装**，等完整立绘、动作确认后再处理。
- `excluded`：明显不符合成熟风格选择，**不参与精选安装，也不能获得风格/鞋履精选标签**。

未声明该字段的第七批及后续候选不能进入安装器。第二至第六批属于历史数据，安装流程保持原状；后续可以继续清查不符合成熟风格的候选。

## 复核升级流程

待核资源如要重新进入精选，需提供完整立绘/模型实际画面证据，检查人物整体视觉年龄感、动作和鞋履，再明确更改 `maturity_screen` 为 `candidate` 并记录审核依据。不能因为同名资源出现在公开哈希清单中，就自动判为符合成熟风格。
