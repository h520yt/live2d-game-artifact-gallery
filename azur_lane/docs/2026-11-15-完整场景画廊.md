# 碧蓝航线 · 立绘画廊完整场景（2026-11-15）

## 本次改动

原来的画廊只展示 `data/paintings/*.png` 里各张独立素材，缺少人物＋场景的合成入口。现在：

- **完整场景默认打开**：人物 PNG + 同皮肤 `_bj/_bg/_back` 背景，存在前景时再叠加 `_front/_middle` 等分层。
- **原始素材保留**：在皮肤详情中切回「原始素材」，可以逐张查看原始立绘、变体、背景和部件。
- **卡片预览**：有对应背景素材时显示人物＋背景缩略预览；没有时继续显示人物。
- **形态选择 / 比例 / 左右 / 上下 / 前景开关 / 重置 / PNG 导出**：都在完整场景面板中。
- **图层坐标**：新重建立绘生成 `*.meta.json`，记录 Sprite Mesh 的边界坐标；各图层都有边界数据时尝试同坐标叠放，否则使用居中自动排版，并在页面明确提示需手动校准。
- **严格匹配**：只从相同皮肤资源名前缀中选分层；`hu_2` 不会误包含 `hu_20`。按 `n/rw/hx` 等形态标记优先找专属背景；无背景时不把其他背景乱配上。

**限制**：这属于静态合成，不等于恢复全部 Live2D 动作、粒子、3D 景深、游戏场景摄像机配置。Mesh 坐标不能保证代表最终游戏中的场景摆放；页面明确区分自动排版和有坐标的初步对齐，不应宣称 100% 官方场景还原。

## 已安装皮肤补背景（推荐）

在项目根目录打开 PowerShell：

```powershell
git pull origin main
python azur_lane/scripts/install_scene_layers.py --plan
python azur_lane/scripts/install_scene_layers.py
python -m http.server 8000
```

浏览器打开：`http://127.0.0.1:8000/azur_lane/viewer/index.html` → **立绘画廊** → 皮肤卡片 → **完整场景**。

- `--plan`：仅检查当前已安装的角色 PNG、哈希表中是否有匹配的背景/前景，以及预计下载量。
- `--only baifeng_3 hu_2`：指定皮肤补齐；名字是资源名，不是中文角色名。
- `--geometry`：可选，补齐已安装人物立绘的 Mesh 坐标元数据；需要额外重新提取人物 PNG，资源下载和处理更多。
- `--force`：可选，强制重新重建所选分层；一般不用。
- `data/scene-layer-report.json`：安装完成的本地统计及失败项，不提交到 Git。

脚本只按本地已存在的角色 PNG 定位皮肤，不会为了清单中未安装的角色下载背景。缺少 `data/paintings/` 时，请先运行原皮肤安装脚本。

## 新装第二、第三批

批次脚本现已把官方 Hash 清单中的专属背景/前景也算入绘画包，不再主动排除：

```powershell
python azur_lane/scripts/install_batch2.py
python azur_lane/scripts/install_batch3.py
```

运行后安装脚本会刷新 `viewer/manifest.json`。已经装过皮肤、不想重新检查模型时优先使用上面的 `install_scene_layers.py`。
