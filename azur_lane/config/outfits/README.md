# Live2D 换装

打开碧蓝航线展示柜里的 **Sunshower Fox Bride · 白凤晴雨狐嫁**（`baifeng_3`），在舞台右上方的「换装」中选择「换装 01 · 黑丝皮鞋」。重新进入角色时默认使用「原始装扮」。

## 白凤的实现

本地资源是 Cubism 5 的 `moc3`，由现有 PIXI Live2D 渲染器播放。模型有 83 个动作，两张 4096 × 4096 图集。模型清单和部件中没有可直接使用的鞋袜换装，腿、脚掌、脚趾、局部高光以及特写中的大腿各有 ArtMesh。抬脚时前脚会切换侧面和鞋底朝向镜头的绘制网格。

- 丝袜图集存放的是带有柔和体积光影、细纹和细窄袜口的材质。选择时将材质合成到原图集区域的内存副本上，再沿原始 UV、网格和遮罩绘制。
- 黑色漆皮、圆方鞋头、低跟和金属马衔扣沿用素材 3 的乐福鞋款。默认前脚取自白凤参考画稿，抬脚、鞋底和后景脚分别取自设计图的侧视、底视和斜视画稿。三个前脚画幅分别绑定 `ArtMesh13`、`ArtMesh229`、`ArtMesh223`，后景脚独立绑定 `ArtMesh18`，由鞋面遮住的 `ArtMesh156` 脚趾随换装隐藏。
- 各视图用当前帧的脚部顶点驱动局部三角网格。默认前脚先画后侧鞋帮、内腔和鞋舌后壁，再画袜脚、前侧鞋帮和饰件。鞋口包边在相交的原小腿层之后绘制。默认前脚的足缘裁剪沿鞋口和有后壁兜底的鞋舌区域生效，`ArtMesh214` 的局部裁剪仅随该视角启用。脚底朝向镜头时使用鞋底边、前掌纹和后跟纹。前脚交接用实际透明度和绘制顺序确定主导视图，并合并该组的可见度。

在查看器网址加上 `?shoe_debug=1`，打开白凤并选择换装 01，左侧面板会显示纯色分层、网格、实际绘制调用和姿态参数。可隔离袜脚或任一鞋层，选「正式贴图」可在同一姿态恢复原色。
- 展示柜播放的是烘焙后的二维图层，视角和光照来自图集。更换模型版本、图集排布或增加足部视角时，需要复查绑点、落点和遮挡。共享适配器面向项目附带的 Cubism WebGL 渲染器。

## 加入换装 02、03

1. 在 [index.json](index.json) 对应的模型 ID 下追加一项。比如 `{"id":"outfit_02","name":"换装 02 · 灰丝皮鞋","enabled":true,"file":"baifeng_3/outfit_02.json"}`。`enabled: false` 只停用该项。使用清单中的实际模型 ID，各模型可以独立登记，找不到可用换装的模型会隐藏控件。
2. 在模型目录中新增描述文件和透明 PNG。白凤的 [outfit_01.json](baifeng_3/outfit_01.json) 及 [outfit_01.png](baifeng_3/outfit_01.png) 可以作为同模型的起点。换颜色、金属配件或表面材质时，可保留图块位置和绑点，另存一份图集，由描述文件的 `atlas` 引用。
3. 为其他模型或明显改变外轮廓的鞋履重新拟合。每个 `patches` 项用 `drawables` 指定 ArtMesh ID，`source: [x,y]` 指定原图集左上坐标，`region: [x,y,w,h]` 指定新图集中的同尺寸材质图块。同项内的 ArtMesh 必须使用同一张原图集并落在该原图块内。可选的 `coverage: [x,y]` 指定新图集中与材质图块同尺寸的 Alpha 遮罩，透明区域会裁掉附件覆盖的旧网格像素。
4. 每个 `attachments` 项对应一件附件。每个 `forms` 项含驱动网格 `anchor`、`grid: [列数,行数]` 和单张 `region` 或多张 `layers`。按行写入每个画稿顶点的 `bindings`，每个绑点由一组 `[ArtMesh 顶点序号,权重]` 构成，权重之和为 1。先在参考姿势中对齐鞋口、前掌和后跟，再用邻近顶点拟合画稿网格。单件附件的替代视图写在同一个 `forms` 内，`mergeViews: true` 按透明度和层级合并互斥的脚掌绘制。`over` 指定需要在其后绘制的足部层，`hide` 指定被覆盖的旧脚趾或鞋履层。
5. 检查默认姿态、伸腿、抬脚、脚底朝向镜头、特写以及切回原始装扮。确认动作播放、缩放、平移和前景遮挡正常。

多层局部网格用 `size: [w,h]` 定义画幅。每层的 `region: [x,y,w,h]` 包含完整画幅及其透明留边。鞋面和鞋底共享网格，使相邻的边在动作中接合。可选的 `warpRest` 按 `bindings` 的顺序列出参考姿势下各加权绑点在画幅中的像素坐标，用于将鞋头、鞋跟延伸到原脚掌轮廓之外。`behind: true` 将该层放在袜脚之前。使用 `warpRest` 的完整画幅层还可设置 `stiffness` 和 `pivot: [u,v]`。`stiffness` 在 0 到 1 之间，将图层从局部形变逐渐混合到相似变换，`pivot` 是跟随局部网格的连接位置。白凤用这一设置减小马衔扣的拉伸。`shadow` 指定地板绑点和绘制层，`groundPoint: [u,v]` 指定接触阴影的中心。

前景图层可用 `after` 额外指定需要遮挡的 ArtMesh。只有该 ArtMesh 当前可见且原绘制顺序比默认锚点更晚时，图层才会延后。材质补丁可用 `whenForm` 指定生效的视图锚点，主导视图改变后会恢复默认补丁。白凤用它控制鞋舌旁相邻袜脚的 Alpha 裁剪。

白凤的鞋底正视使用 `soleSupport`。同一列的前掌与后跟控制点定义鞋底参考轴，`rowStiffness` 控制各行向该参考轮廓收敛的程度。鞋底边、前掌纹和后跟纹共用修正后的网格。侧视与默认视角继续用各自的鞋面、鞋帮和鞋跟绑定。

相邻前脚视图可在 `bridges` 中登记过渡。两端的 `fromUV` 和 `toUV` 指向鞋跟、鞋口、扣带、鞋底接缝和鞋头的对应位置。过渡根据两端实际绘制贡献插值同一张网格，并从图集中选择当前视角画稿。每个阶段各有一个脚前层及可选的脚后层。两端不再同时可见时恢复对应视图的原鞋层。测量方法、运行时数据与固定机位截图见[白凤鞋底形变记录](../../../verification/baifeng_3-shoes-stage2/README.md)。

旧配置可继续用 `grid: [2,2]` 和 `rigid` 做整体拟合。`rigid` 根据 `bindings` 的顺序列出参考画幅上的绑点坐标。裁切后的图层可用 `frame: [x,y,w,h]` 指定它在画幅中的位置和大小，`rotation` 控制绕图层中心顺时针旋转的角度。单图块视图可用 `underlay: [x,y]` 指向同尺寸的鞋口内层。

安装 `baifeng_3`、`qiye_10` 并准备 Chrome 和 Playwright 后，可以从项目根目录运行 `node azur_lane/tests/test_outfits-browser.cjs`。脚本检查换装失败重试、重复换装与恢复、动作与视角保持、脚部网格交接、袜脚前后的绘制顺序、扣饰连接点和未配置模型的控件显示。`touch_drag9` 和 `touch_body` 按 60 帧每秒检查，其余动作抽样渲染。
