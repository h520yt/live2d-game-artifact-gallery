## 使用

    git pull origin main
    python reverse1999/scripts/sync.py showcase 308603
    python -m http.server 8000

浏览器访问 http://localhost:8000/reverse1999/viewer/ ，搜索“露西”或“308603”，选择“完整皮肤展示”条目。

交互：切换商城动作、隐藏/显示背景、背景铺满/完整显示、平移/缩放人物。

## 验证范围

这是基于真实资源的分层皮肤预览样板，不等同于 Unity 游戏客户端逐帧复刻。

已处理：皮肤专属背景 PNG + 商城 Spine 动画、背景人物分层、手动调整、动作列表。

仍未校准：原版游戏的背景机位、实时粒子/光影、复杂交互脚本、音频、动态镜头及其他材质效果。不能把骨骼渲染图描述为“官方原画”。

可扩展性：在 scripts/showcase.py 的 SCENES 中按同衣着 ID 确认相应背景及商城动画后，才开放更多皮肤配方；目前只纳入经过目录和实际骨骼头检查的 308603。

自动测试包括路径/ID 安全、资源缺失与版本检查、索引生成、下载文件列表；真实上游下载另由 CI 验证。最终视觉仍需本机对比游戏画面。
