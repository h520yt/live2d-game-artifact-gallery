# 《重返未来：1999》商城皮肤场景适配记录（2026-11-13）

## 需求与实现范围

将「完整皮肤展示」作为新的预览模式，支持一套已验证的商城皮肤的同 ID 真实背景 + 商城专用 Spine 模型组合显示，而不是将普通战斗模型叠在随意图片上。

本次样板：贝丽尔「释命运以弦音」，ID 313403。

## 已核对的上游原始素材

资源库：https://github.com/myssal/Reverse-1999-CN-Asset

- 角色与衣着映射：mappings/ArcanistMap.json（313403 对应贝丽尔「释命运以弦音」）
- 专属背景：singlebg/skin2dbg/313403.png（9,438,795 字节）
- 商城骨骼：roles_bust/v4a0_313403_ble_skinstorecardface/313403_ble_skinstorecardface.skel（Spine 4.2.36）
- 商城图集：roles_bust/v4a0_313403_ble_skinstorecardface/313403_ble_skinstorecardface.atlas
- 商城贴图：roles_bust/v4a0_313403_ble_skinstorecardface/313403_ble_skinstorecardface.png（4,154,336 字节）
- 此外的同 ID 角色普通立绘骨骼：roles/v4a0_313403_ble（独立保存，不代替商城特供资源）

注意上游还存在 skinstore、skinsuit 和其他商城版本骨骼。其中 skinstore 的图集指向其他目录的 PNG，所以样板优先选择 skinstorecardface 的自包含配对，避免加载时缺贴图。

## 变更

- 新增 reverse1999/scripts/scene.py：扫描同 ID 商城背景、识别对应的商城专用骨骼、检查 atlas 贴图页、自包含资源下载、生成独立场景描述文件
- sync.py 增加 scene 动作，统一清单自动合并 type=scene 的记录
- viewer/index.html 增加商城场景组合预览：实际背景与透明骨骼动画叠放，开放动作选择
- README 增加示例和资源来源
- tests/test_scene.py 增加场景目录选择、图集解析、清单完整性测试

## 个人本地复现

    git pull origin main
    python reverse1999/scripts/sync.py scene 313403
    python -m http.server 8000

浏览器进入 http://localhost:8000/reverse1999/viewer/，搜索「贝丽尔」，选择「商城场景（组合预览）」。

原始素材及第三方运行时只存于忽略 Git 的本地 data/scenes 和 vendor，绝不提交游戏素材。
