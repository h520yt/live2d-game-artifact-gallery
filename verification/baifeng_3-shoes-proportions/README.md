# 白凤默认姿态鞋型与鞋口验收

浏览器定格在 `Param71 = 0` 和脚部形变参数的默认值。同一组对比固定机位、缩放和裁切。图中的粉线是原始脚部贴图 Alpha 轮廓，青线是各鞋履图层合成后的轮廓。原始前景脚包含 `ArtMesh13` 和独立脚趾 `ArtMesh230–235`，后景脚包含 `ArtMesh18` 和 `ArtMesh156`。跟点取原 ArtMesh 顶点，踝心取袜脚横截面中心，脚背取截面的上缘。

## 比例

以下是参考画幅内的二维投影测量，单位为像素。两鞋的参考画幅各自独立。前掌和鞋底分别在修复前后使用同一截面。

| 项目 | 前景鞋 | 后景鞋 |
|---|---:|---:|
| 鞋尖 X | 366 → 352，原脚尖 355 | 329 → 323，原脚尖 318 |
| 前掌投影截面宽 | 98 → 83，原脚 87 | 71 → 65，原脚 79 |
| 鞋底侧壁截面厚 | 24 → 17 | 10 → 8 |
| 后缘 X | 38 → 38 | 57 → 57 |

前景鞋从接近扣带的位置开始沿鞋长逐步收短，前掌与中底下缘各有自己的收敛曲线。计入独立脚趾后，前景鞋整个可见长度缩短约 4.3%，视觉上主要减少了鞋尖和鞋底下缘的余量。第一版缩短约 32 像素，叠线显示鞋尖比裸足占位更靠后，最终收回到 14 像素。后景鞋靠脚跟独立量测，只在前掌区域进行较小幅度的修整。两只搭扣的原贴图和位置经逐像素验证一致。

## 鞋口几何

纯色检查能看到旧鞋舌和鞋舌后壁之间有一段边缘分离，残余的袜脚边缘又从两者之间露出。将鞋舌局部放低，沿实测的脚背方向连接到鞋面和两侧鞋帮。鞋舌轮廓同时用于实心皮革和包边，后帮和后壁仍在脚后，鞋口前缘通过真实的轮廓重叠遮住脚背。两块足部遮罩只在接触区调整，边缘抗锯齿约 1–2 个画幅像素。内腔保留窄暗边，袜脚和包边之间的层次可在关闭材质后的画面上看到。

缩短前掌后，隔离渲染发现鞋尖旁的硬影来自原地面 ArtMesh798。为这一层添加 `ArtMesh13` 视角的局部 Alpha 补丁，跟部和地板原图保留。默认姿态检查中，前缘没有明显穿出，鞋舌旁原先的灰黑楔形被连续的皮革边覆盖。

## 范围

默认前景及后景鞋的 35 点绑定、鞋层绘制顺序和两只扣饰沿用原配置。抬脚、底视和过渡画稿逐像素一致。88 个原模型文件的 SHA-256 与基线一致。目视验收只覆盖默认姿态，动作回归用于核对程序行为。
