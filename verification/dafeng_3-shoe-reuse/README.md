# 大凤 `dafeng_3` 原生鞋履提取与白凤复用验证

## 结论

**方案 B：可复用原生美术，但需要重新适配白凤的 UV 和透视。** 大凤的鞋头、鞋舌、皮革反光、围条缝线和横带装饰来自可独立提取的原始图集。白凤的两脚朝画面右侧，大凤的两鞋朝画面左侧，镜像后鞋口位置、纵向透视和后跟投影仍有差异。试验给前景鞋和后景鞋各做了一套定位点，将大凤原生材质投影进白凤原脚 UV，并继续使用白凤现有鞋口、遮挡和轮廓补层。

Chrome 的同机位 WebGL 渲染显示，两只鞋均保留了大凤的包头缝线、横带及三格金色饰线，鞋口沿白凤脚踝收边。以当前换装中实际参与贴图编译、Alpha 大于 16 的足部材质和轮廓补层像素为分母，前景鞋 **96.6%**、后景鞋 **96.3%** 的像素由大凤采样颜色占至少一半。该统计是图集像素权重，含边缘延色和被挡住的像素。后景鞋跟受前脚遮挡，近景无法完整验收该部位。 [三版同机位对比](comparison.png) · [正式版与试验合计像素差异](trial/browser-checks.json) · [图集采样权重](trial/fit-metrics.json)

## 二、原生结构与动作

- **前景。** `ArtMesh135` 是袜脚，`ArtMesh98` 是邻接小腿，脚腿以 `Glue__ArtMesh98__ArtMesh135` 衔接。鞋 `ArtMesh34` 与 `135` 共享上游 `Rotation33`，近端分别走 `Warp15 → Warp39` 和 `Warp13 → Warp16`，无鞋脚 Glue。默认袜脚 394 先画，鞋 396 后画，Alpha 阈值 127 下鞋和袜脚重叠 **16.0%**（以鞋网格为分母）。两片共同运动、分别校正，鞋帮通过绘制顺序压住袜脚边缘。
- **后景。** 默认穿着的外鞋 `193` 和内衬 `194` 有同一条变形器链，从 `Warp43` 起。袜脚 `170` 从 `Warp80` 起，与鞋在 `Rotation63`、`Warp231` 汇合。默认顺序 **17 内衬 → 237 袜脚 → 327 外鞋**。内衬与袜脚重叠 **87.7%**，外鞋与袜脚重叠 **64.4%**，这分别对应鞋口被袜脚挡住和外鞋覆盖袜脚的区域。袜脚 `170` 和小腿 `138` 有 Glue，鞋外部与袜脚之间无 Glue 或 Cubism 裁剪遮罩。
- **鞋底形变。** 鞋面和可见鞋底位于同一三角网格，局部可以产生不同的位移。单独将 `Param28` 从 0 推到 30，前景鞋网格边长比的 P10、P50、P90 为 **0.6605 / 0.9542 / 1.3988**，实测有局部拉伸。单扫 `youjiaoxuanzhuan` 的三个键值，穿着后鞋外部的边长比仍为 1.0000（四位小数），该参数在这个探测中表现为刚体运动。两鞋均未识别出给外底或鞋跟单独绑定的 ArtMesh。 [坐标和重叠实测](measurements.json)

**大凤确有原生单脚脱鞋动作。** `tuoxie` 从 0 到 1.5 时，默认后景鞋 `193/194` 的 Alpha 从 1 降到 0，原本隐藏的 `182/183` 从 0 升到 1，切到由 `Warp145 → Warp221 → Rotation45` 等驱动的另一条链。`touch_body` 约 **6.20 秒**仍在穿着，**8.40 秒**后景袜脚已经离开空鞋，**12.00 秒**恢复穿着。`home` 约 **2.40 秒**也能看到空鞋与袜脚分开。`login` 的曲线和 Core 同样复现脱鞋态至穿着态的切换。`chatui` 在相关动作里切出 `184/162` 的袜脚与腿的替代画片。`JIAOXIEx`、`JIAOXIEY`、`jiaoxiejd` 分别影响穿着后鞋的位置或转动，单独扫描时袜脚不随它们变化。`xiebianhua` 在 MOC3 无键绑定，三个探测值下鞋网格和透明度没有变化。 [大凤动作渲染](native/shoe-state-motion.png) · [Motion 和物理配置索引](motion-inventory.json) · [Core 扫描](motion-sweep.json)

全部 14 个 motion 按原始 30 FPS 时间格、相关曲线关键时间和结束时间取样，共 **6,587** 帧。另对相关参数逐一试探键值或范围边界。物理配置包含 12 组，其中第 11、12 组的 `zdtwl`、`zxtwl`、`ydtwl`、`yxtwl`、`zuodatuishangxia` 与腿脚变形链相交。动作证据是离线将 motion 曲线取值写入实际 Cubism Core 的确定性样本，前后镜头的游戏运行时混合、随机物理和交互逻辑超出验证范围。`home`/`login` 开头还有整层淡入，不能把该段前景鞋的透明度变化解释成前景脱鞋。

按原任务的结构分类，**A** 可提取独立鞋外片，**B** 穿着态鞋与脚沿用共同上游变形，**C** 皮鞋内部细节为同片图案，**D** 后景鞋有穿着与脱下的独立网格状态。后景鞋两状态复用同一组原画，可在原画与既有网格中改变投影和遮挡；未发现第二款鞋、独立正底纹理或完整多角度鞋套装。最适合的提取单位是两只完整外鞋加后景内衬。

## 四、哪些可以带到白凤

| 部位 | 结论与处理 |
| --- | --- |
| 原生整片鞋图能否直接贴入 | 不能。两只鞋的轴向、鞋口和后跟落点不同，源鞋外片与白凤脚趾分片也没有一一对应的 UV。试验用前后两套各 15 个定位点做镜像和非刚性透视适配，再按白凤各网格的 UV 三角形逆采样。大部分原生颜色和线条直接来自图集采样。 |
| 鞋头、鞋舌、鞋面、鞋帮及装饰 | 可复用原画。鞋舌、横带和金色饰线随各自的鞋面映射。试验保留大凤的横带式装饰。若目标外观指定白凤现版的银色马衔扣，需要为两种透视另画扣件、接触阴影和遮挡。大凤图集里没有可拆出的马衔扣。 |
| 鞋口和脚踝 | 可贴合，但使用白凤现有的踝部颜色叠加、鞋口 Alpha 和局部轮廓。直接移植后景空鞋内衬会改变穿着态的踝部遮挡。若制作白凤空鞋状态，应重新裁配该内衬。 |
| 鞋跟、鞋底、趾间补色 | 源材质可以投影。可见底跟外形、后跟厚度、接地点、趾间的连续包头按白凤轮廓处理。此次复用了现有轮廓补层和覆盖蒙版，趾尖边缘用源图延色。单独鞋底视图及默认被挡住的后跟完整画面需要另行适配。 |
| UV 和 JSON | 保留白凤现有 UV、顶点/索引、绘制顺序、局部踝部叠层和附件顶点绑定。试验 `outfit.json` 与工作区现版配置只有 `atlas` 值不同。所有覆盖蒙版逐字节一致，已有 JSON 结构无需更改。 |
| 是否增加图层 | 默认姿态无需新增。继续用 `ArtMesh13/18` 锚定的两张既有轮廓补层以及 `ArtMesh12/217` 的踝侧处理。 |
| 是否要重制动画 | 默认静态试验无需重做动画。白凤的 `229` 抬脚片和 `223` 底视片在默认态隐藏，绑定链受 `Param71` 等影响。本试验没启用这些姿态，如以后扩展到它们，需要适配对应画片、视角及遮挡，无法照搬大凤的脱鞋链或顶点序号。 |
